# Compatibility matrix

The maintained compatibility view is [Current Compatibility
Matrix](status/CURRENT_COMPATIBILITY_MATRIX.md). Historical 0.6.2 results and
their 80 Pending cases are preserved in the [0.6.2 release evidence
archive](archive/releases/0.6.2/).

Automated/source evidence must not be read as gameplay compatibility. Only the
current exact-artifact live report can change a surface from Pending.
