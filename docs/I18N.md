# Internationalization

Version 0.7.0 provides `en-US` and `pt-BR` catalogs. English is the fallback;
the BeamNG UI language is the default preference. The Settings tab can select
automatic, English, or Brazilian Portuguese, and the preference is persisted
through settings schema 9 rather than relying on localStorage.

Keys are stable and semantic. The service supports safe text interpolation,
one/other plural forms, and locale-aware number formatting. It never renders
catalog content as HTML. Missing keys return the technical key so a catalog
defect stays visible.

Translation is presentation only. The following never use translated labels as
identity or ordering input:

- seeds and PRNG streams;
- model/configuration/part/path keys;
- Vehicle DNA, fingerprints, lineage, and replay;
- lock categories and slot identities;
- Race Policy field IDs and deterministic selection;
- lifecycle, protocol, capability, and diagnostic codes.

Both catalogs have identical key sets. Automated tests cover both locales,
fallback, missing keys, interpolation, pluralization, long Portuguese strings,
number formatting, and absence of HTML. Visual clipping and live game-language
switching remain in the owner plan.

To add a locale, copy the English key set, translate display strings without
changing placeholders, add it to the service allowlist and preference schema,
then extend parity and long-string tests.
