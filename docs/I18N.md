# Internationalization

The canonical v0.7.7 terminology policy is
[`I18N_TERMINOLOGY.md`](I18N_TERMINOLOGY.md). Backend result/phase codes are
stable data, not user copy. Normal notifications and progress resolve through
the en-US, pt-BR or es-ES catalog; backend English is diagnostic context only.

The app supports parity-complete internal `en-US`, `pt-BR`, and `es-ES`
catalogs. English is the safe fallback. Automatic mode maps BeamNG locale
families (`pt-*`, `es-*`, `en-*`) to these catalogs; a persisted manual setting
can override and return to automatic.

## Two catalog scopes

- `locales/translations/<locale>/main.translation.json` is the official BeamNG
  package surface for the host-visible app name and description.
- `ui/modules/apps/soturineChaosRandomizer/i18n/<locale>.json` is the Vue app
  catalog for controls, statuses, progress, empty states, and diagnostics.

The narrow host catalog intentionally delegates all app content to the internal
catalog, preventing two competing translations for the same screen string.

Keys are semantic and values are rendered as text, never HTML. Missing known
presentation keys use a safe humanized fallback instead of exposing the raw key.
Internal identifiers—seed streams, model/config/part keys, slot IDs, Vehicle DNA
fingerprints, protocol codes, and lifecycle generations—remain language neutral
and never drive ordering or selection through translated labels.

Technical IDs may appear in explicitly marked Details/developer disclosures.
Normal UI prefers a game-provided human name, then a safe derived label. Catalog
parity, interpolation, plural forms, alias mapping, raw-key prevention, and all
packaged host locales are automated. Actual BeamNG locale enumeration and
runtime fallback are **Pending owner validation**.

Normal UI translates placement reasons, preview kinds/states, terminal statuses,
and Race policy through stable catalog keys. The shared part glossary humanizes
known generic registry labels while preserving authored third-party brand and
product names; raw paths and codes remain diagnostic-only.

`ui/modules/apps/soturineChaosRandomizer/i18n/terminology.js` is the executable
termbase for the official/short product names and intentionally preserved
technical terms. Catalog validation consumes that same source; normal UI copy
still translates the surrounding sentence. Unknown runtime result or phase
codes resolve to a translated generic label and remain visible only in Details.
