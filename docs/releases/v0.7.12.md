# Soturine's Chaos Randomizer v0.7.12

BeamNG.drive 0.40 compatibility **experimental prerelease**, targeting
BeamNG.drive 0.40.4 (minimum 0.39). Every engine API the mod calls was checked
against the installed 0.40.4.0 source; see
[BeamNG 0.40 compatibility](../BEAMNG_0.40_COMPATIBILITY.md) and the
[audit report](../testing/v0.7.12/AUDIT_REPORT.md).

## Fixed

- **Every local player is protected, not only player 0.** In 0.40 split-screen
  any player can walk into a car. Race cleanup, Remove, Position All and AI
  start now refuse a car with any player inside, and Chaos refuses a car shared
  with another player or the walking character.
- **Chaos never writes to another player's car.** While a split-screen player
  has their car open in the configuration menu, BeamNG 0.40 redirects the
  implicit part API to that car; the mod now binds its writes to its own
  vehicle in that case and no longer reads that car as its own.
- **AI status is confirmed, not assumed.** The old check looked for an AI-mode
  getter BeamNG does not have, so a queued command was shown as running. The
  mode is now read from the vehicle; no reply stays "unconfirmed".
- **Reset AI** is available in the Start step (the command existed without a
  button).
- The "transfer ownership" hint pointed to an action that never existed; the
  message now says to remove the car from the event.

## Added

- **Recorded route.** Drive your own car with *Record my route*, then choose
  *Recorded route*: opponents replay the path with BeamNG's own path follower,
  each starting from its own slot. This replaces a per-opponent Recording
  toggle that had no effect.

## Changed

- Target BeamNG 0.40.4; 0.39 stays the minimum. Interface imports are checked
  against the real 0.40.4 interface exports.
- Release checks: an experimental prerelease can now publish known live
  failures, but never hide them - the notes must repeat the live report's exact
  counts and disclose failed or blocked cases.
- Removed dead code (functions with no caller) and merged two copies of the
  vehicle/configuration anti-repeat picker; seeds reproduce the same vehicles.

## Validation

Automated validation: Passed.

Live BeamNG validation: Pending owner validation.

Live cases: **0 executed / 0 passed / 0 failed / 18 pending / 0 blocked**.

Lua contract tests cover split-screen occupancy, the config-target redirect,
the AI mode probe (executed as Vehicle Lua and GE Lua text), the path recorder
and Recorded playback; seven deliberate defects were each caught by them. They
do not prove split-screen, AI movement or rendering in the game; see
[live results](../testing/v0.7.12/LIVE_RESULTS.md).

## Known limitations

- No BeamNG 0.40 session has run this mod yet; all 18 live cases are pending.
- Split-screen protection is built on the game's 0.40.4 source contracts and has
  not been exercised with two physical players.
- The interface ships in English, Português (Brasil) and Español; the other
  requested languages fall back to English.
- PS5 does not support mods; the ZIP is for PC.

Only the deterministic ZIP, `.zip.sha256` and manifest are supported assets.
GitHub source archives are not mod packages.
