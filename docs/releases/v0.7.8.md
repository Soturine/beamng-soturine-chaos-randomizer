# Soturine's Chaos Randomizer v0.7.8

Live-findings stabilization **experimental prerelease** targeting BeamNG.drive
0.39.4.

## Fixed

- Replaced fixed per-tab normal heights with content-driven child geometry,
  while preserving a later explicit AppHost resize and compact mode.
- Normalized Preview slot collections and legacy formation values at ingress,
  so Formation no longer assumes an array and UI business state uses stable
  canonical codes.
- Made the `BngSmartSelect` adapter always pass a normalized array, including
  defensive handling for object maps, nulls and malformed entries.
- Added deterministic bounded alternatives for blocked, missing-ground and
  excessive-slope placement candidates instead of failing at the first sample.
- Protected the player as an occupied staging object and kept generation
  staging separate from final formation and optional Preview rendering.
- Reflowed long GlobalStatus messages and actions at narrow AppHost widths.

## Changed

- Scramble and Full Random status/details derive parts, tuning and paint counts
  from their final coverage ledgers and read-back classifications. Partial
  application remains visible and no complete parts tree is serialized.
- Placement results expose attempt/rejection totals, bounded rejection samples,
  selected fallback depth, budget exhaustion and measured planning duration.
- Preview data readiness, renderer visibility and autonomous generation remain
  independent states; Race option changes mark old Preview data stale.
- pt-BR and es-ES Preview/staging messages use natural user-facing language
  while protocol codes remain technical-only.

## Known limitations

- Gameplay, D3D11/D3D12/Vulkan rendering, Preview visibility, controller/UINav,
  UI scale/safe zones, locale rendering, third-party vehicles, AI behavior and
  performance require owner execution with the exact downloaded release ZIP.
- An exhausted placement budget still fails closed; Details reports the bounded
  attempts and rejection causes so the owner can change origin/spacing safely.
- Pega-Pega/Tag remains foundation-only and BeamMP support is not claimed.
- Broad `main.lua` and `apiAdapter.lua` decomposition remains v0.8.0 debt.

Only the deterministic ZIP, `.zip.sha256` and manifest are supported assets.
GitHub source archives are not mod packages.
