# Soturine's Chaos Randomizer v0.7.3

Experimental prerelease.

## Fixed

- Replaced native Runtime UI selects with a shared `BngSmartSelect` adapter and
  normalized map/array state before components consume it.
- Isolated app, tab, and Race-step render failures without unmounting the shell.
- Enforced one-target Random Car/Full Random cardinality, same-object Scramble,
  callback generation/phase/vehicle ownership, and slot-exclusive Race vehicles.
- Made Safety ternary and bounded so unknown/transitional reads cannot authorize
  destructive recovery.
- Added semantic watchdog deadlines, terminal Race outcomes, structured progress,
  compact layouts, scoped expiring status, human lock UI, and accurate counters.
- Prevented stale callbacks and ID reuse from mutating a newer operation.

## Changed

- Progress now publishes phase and overall fractions with operation/race/slot
  context; Vue owns translation and percent formatting.
- Race exposes planned, selecting, spawning, binding, randomizing, validating,
  ready/warning, partial, failed, cancelled, and skipped lifecycle states.
- UI uses progressive disclosure and hides technical identifiers outside
  explicit diagnostic views.
- `VERSION` is canonical and derived metadata is automatically checked.
- Declared project/package/release license is Apache-2.0, matching `LICENSE` and
  `NOTICE`. Sass was removed because runtime styling is plain CSS.

## Performance

- Cooperative work, centralized short phase/slot limits, semantic watchdog
  progress, bounded diagnostics, and resource cleanup are covered by automated
  fake-clock, fault, mount, and instrumentation tests.
- Mounted synthetic tab/button p95 remains below the 50 ms regression budget.
  This is not a BeamNG FPS or live-latency claim.

## Compatibility

- Primary target is BeamNG 0.39.4; 0.39.2.1 remains the historical baseline for
  prior live failures.
- Packaged BeamNG locales provide en-US, pt-BR, and es-ES app metadata while the
  internal Vue catalogs translate the complete interface.
- Sanitized fixtures cover registry/config name divergence, subgroups, metadata
  changes, instability, spawn refusal, identity reuse, and managed AI lane policy.
- `0.39.4 changelog not yet publicly documented at implementation time`

## Validation

Automated validation: passed.

Live BeamNG 0.39.4 validation: **Pending owner validation**.

The deterministic ZIP, checksum, and manifest are release assets. Automated and
fixture results do not assert that gameplay passed inside BeamNG.

## Known limitations

- Outer AppHost frame migration, safe areas, UI scaling/alignment, controller
  navigation, renderer behavior, third-party content, and all gameplay cases
  still require the owner to execute the downloaded asset.
- Intel+D3D12 VRAM/OOM incidents require hardware evidence and must remain
  separate from mod cardinality/memory-pressure classification.
- The current `main.lua` composition root and broad API adapter are scheduled
  for v0.8.0 decomposition, not claimed here.
- Exact Vehicle DNA restore depends on installed compatible content; unsupported
  differences may produce an explicit partial result.
