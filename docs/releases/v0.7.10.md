# Soturine's Chaos Randomizer v0.7.10

Race stabilization and simplification **experimental prerelease** targeting
BeamNG.drive 0.39.4.x. Every fix below traces to the owner's v0.7.9 live
session; see the [root cause report](../testing/v0.7.10/ROOT_CAUSE_REPORT.md).

## Fixed

- **World Preview draws again.** The renderer rejected BeamNG's `ColorF`
  binding (a callable class, not a Lua function), so no marker was ever drawn.
  Bindings are now injected and probed by calling them; a missing binding is
  named instead of "renderer unavailable". The AI destination marker is fixed
  by the same change.
- **Race generation no longer ends empty while safe candidates exist.** Custom
  keeps its own policy instead of inheriting the previous preset; rejected
  slots no longer constrain the pool; an empty pool relaxes variety only; slots
  retry automatically and fall back to one verified official vehicle when the
  policy allows it.
- **Rejected candidates are removed**, after proving they came from the exact
  operation that produced them.
- **Position All is one fast batch** with parallel readback, settling-tolerant
  confirmation and a retry of only the slot that failed.
- **Line and Grid keep their shape.** Side-by-side neighbours were mistaken for
  overlaps, which forced a deformed per-slot fallback even on an empty map.
- **Behavior starts with the opponents that are ready** and reports
  "2/3 NPCs started · 1 could not start" instead of blocking everything.

## Changed

- Events is four clear steps — Setup, Formation, Behavior, Start — with
  technical and advanced options behind one disclosure per step.
- Readiness is computed once in Lua and presented by the UI.
- Validation is one command, `npm run verify`; packaging no longer re-runs the
  test suites and the release manifest describes only the artifact and its
  evidence.
- Removed unused modules (legacy lineup facade, playground/contact
  foundations, separate lineup storage), duplicate Preview code and payloads,
  and orphaned translations/CSS.

## Validation

Automated validation: Passed.

Live BeamNG validation: Pending owner validation.

Live cases: **0 executed / 0 passed / 0 failed / 15 pending / 0 blocked**.

Automated contract tests prove the Preview frame loop with engine-like
bindings, pool relaxation, recovery, discard authorization, Custom policy,
canonical readiness, batch placement, formation geometry and the Events UI
flow. They do not prove visible markers, physical AI movement, AppHost pixels
or live performance; see [live results](../testing/v0.7.10/LIVE_RESULTS.md).

## Known limitations

- All 15 live cases require owner execution with the exact downloaded ZIP.
- D3D12, Vulkan, controller/UINav, UI scale/safe zones, third-party vehicles,
  BeamMP and live performance remain unvalidated.
- A formation can still degrade explicitly when the requested area has no safe
  solution.
- Broad `main.lua` and `apiAdapter.lua` decomposition remains v0.8.0 debt.

Only the deterministic ZIP, `.zip.sha256` and manifest are supported assets.
GitHub source archives are not mod packages.
