# Soturine's Chaos Randomizer v0.7.4

Live-derived stabilization **experimental prerelease** targeting BeamNG 0.39.4.

## Fixed

- Replacement cardinality now evaluates the operation's expected source removal, candidate addition, owned temporary and accepted IDs; unrelated world changes remain diagnostic.
- Terminal results distinguish `SUCCESS`, `SUCCESS_WITH_WARNING`, `FAILED_NO_CHANGE`, `FAILED_ROLLED_BACK` and `CANCELLED`, preserving a proven commit point.
- Safety separates runtime integrity, drivability and chaos-policy acceptance. Unknown/pending tree or fluid evidence is non-destructive.
- Race restores player focus after background spawn, retains accepted slot vehicles, contains failure per slot and persists only validated ready DNA.
- Locks use evidence precedence that favors specific leaf identity over generic ancestry.

## Changed

- Race provides read-only generation and final-grid world overlays with slot number/name, transform, heading, footprint, margin and state. Preview never spawns, removes, focuses, moves or changes physics on a vehicle.
- Runtime UI responsiveness follows measured AppHost width from 320 through 720 px. Garage, Locks, Race summaries, every compact tab and idle status presentation use progressive disclosure and human labels.
- Race preview controls expose origin, orientation, formation, spacing, margin and custom position while keeping advanced policy separate.

## Performance

- Full Random instruments and bounds parts reload, readback, repair reload, phase duration and longest cooperative step. Synthetic automated budgets passed; no live FPS or latency improvement is claimed.
