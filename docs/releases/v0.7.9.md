# Soturine's Chaos Randomizer v0.7.9

Race end-to-end stabilization **experimental prerelease** targeting
BeamNG.drive 0.39.4.x.

## Fixed

- Restored command parity for Race AI quick presets and contained rejected
  commands inside the Behavior panel instead of unmounting it.
- Reconciled explicitly removed competitors into an idempotent tombstone state;
  unknown accepted bindings still fail closed.
- Separated formation origin from heading. Participating-player layouts default
  to the player frame, while Camera remains an explicit origin choice.
- Preserved Line/Grid group geometry through bounded whole-group translation and
  spacing fallback before any explicitly degraded per-slot fallback.
- Added a single fast reposition transaction with progress, stable readback,
  cancellation and harmless repeated-click handling for existing competitors.
- Routed world Preview markers through a continuously called BeamNG 0.39.4
  render adapter and kept calculated data distinct from a successfully drawn
  frame.
- Required physical binding, current generation, placement, drivability and AI
  capability before an opponent becomes eligible for managed AI commands.
- Expanded generic Balanced critical-dependency recognition for ICE, EV,
  control and nested functional slots without accepting undrivable candidates.
- Bounded long Participation selection content inside narrow AppHost layouts.
- Excluded external-clock stalls and discontinuities from frame-overrun claims
  while retaining them as explicit contaminated telemetry.

## Validation

Automated validation: Passed.

Live BeamNG validation: Pending owner validation.

Live cases: **0 executed / 0 passed / 0 failed / 15 pending / 0 blocked**.

Automated fixtures prove protocol, ownership, formation planning, read-only
renderer calls, AI eligibility, generic safety policy, UI contracts and package
structure. They do not prove live gameplay, visible D3D11 markers, physical AI
movement, AppHost rendering or performance.

## Known limitations

- All 15 v0.7.9 live cases require owner execution with the exact downloaded
  release ZIP; no v0.7.8 result is inherited.
- D3D12, Vulkan, controller/UINav, UI scale/safe zones, third-party vehicles,
  BeamMP and live performance remain unvalidated.
- Preview renderer mocks prove only adapter behavior. A screenshot and human
  observation are required before world-space marker visibility can pass.
- A bounded placement search can still terminate with an explicit failure or
  degraded layout when the requested area has no safe solution.
- Broad `main.lua` and `apiAdapter.lua` decomposition remains v0.8.0 debt.

Only the deterministic ZIP, `.zip.sha256` and manifest are supported assets.
GitHub source archives are not mod packages.
