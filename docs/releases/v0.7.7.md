# Soturine's Chaos Randomizer v0.7.7

v0.7.6 live-findings stabilization **experimental prerelease** targeting
BeamNG.drive 0.39.4.

## Fixed

- Canonicalizes Garage entry payloads before Saved/Compare/filter consumers,
  preventing the owner-observed non-array render failure while preserving tab
  error isolation.
- Mints a new episode and slot-seed stream for every explicit blank-seed Race
  generation; explicit and Repeat flows remain deterministic and visible.
- Reconciles exact prior Race-owned lineup bindings before replacement and
  makes managed Regenerate an atomic one-slot/one-concrete-vehicle handoff.
- Calculates and executes first/next/all placement independently from the
  optional World Preview renderer, with dedicated forward generation staging.
- Makes Balanced accept non-critical warning/unknown optional evidence while
  still rejecting proven runtime/drivability failure with structured policy
  reasons.
- Stops Mods Showcase at zero-pool preflight instead of creating doomed slots.

## Changed

- Race slots publish one lineage across generation, episode/slot seeds,
  concrete vehicle, managed handle and placement identity.
- Generation, placement, drivability and AI readiness are independent axes.
  AI-ready requires confirmed dispatch/readback, not vehicle existence.
- Pool empty, candidate resolution, policy rejection and exhaustion remain
  distinct diagnostic causes and recovery scopes.

## UX

- Global Details now opens a shared drawer for the exact result, exposes a
  localized summary/recovery action and supports copying technical diagnostics.
- Preview fallback lists calculated placements when the renderer is
  unavailable and never claims visual success from data/marker counts alone.
- Compatibility notice is scoped, localized, dismissible and absent from the
  ordinary supported single-player flow.
- Long selection labels, narrow widths and per-tab normal sizing retain usable
  focus, overflow and AppHost boundaries without reviving the mini-app shrink.

## Race

- New generations reconcile only proven prior Race ownership and refuse unsafe
  cleanup; player, unrelated and remote/unknown-authority vehicles remain
  protected.
- Regenerate keeps the source until a candidate verifies, then removes the
  source and commits the binding; failure/cancel removes only the candidate.
- Canonical competitor order drives display, placement and AI selection.
- Recoverable failures release transient attempt state, preserve requested
  setup and retry with a new operation ID/generation.

## Garage

- Array, object-map, empty and invalid payload shapes converge to one canonical
  collection at ingress. Empty database and empty filtered results use distinct
  localized presentation.

## Known limitations

- Gameplay, D3D11/D3D12/Vulkan rendering, Preview visibility, controller/UINav,
  UI scale/safe zones, locale rendering, third-party vehicles and performance
  require owner execution with the exact downloaded published ZIP.
- Mods Showcase discovery with real installed mods remains a separate live
  branch from the validated automated zero-pool preflight.
- Pega-Pega/Tag remains foundation-only; BeamMP integration is not claimed.
- Broad `main.lua` and `apiAdapter.lua` decomposition remains v0.8.0 debt.

The deterministic ZIP, `.zip.sha256` and manifest are the only supported
assets. GitHub source archives are not mod packages.
