# Chaos

Chaos discovers mounted configurations, the current compatible part tree, public tuning variables, and supported paint fields at runtime. Random Car loads a configuration; Scramble mutates the current logical target; Full Random combines both.

Parts and tuning converge through bounded rescan loops. Chaos 100 selects every eligible unlocked item; lower values use deterministic substreams and classify non-selected entries. Completed means every eligible item reached a terminal classification, not that every value changed.
