# Vehicle DNA

Vehicle DNA is an explicit, schema-validated snapshot captured only after final target, parts, tuning, paint, fuel, and coverage readback. It stores normalized data and fingerprints, not mod archives or executable code.

Exact restore requires strict final equality. Compatible restore reports every omission, mapping, and clamp and requires authorization for partial results. Replay Generation preserves the saved base and generator identity; Pure Seed Replay is a distinct workflow.

See the detailed [Vehicle DNA guide](../VEHICLE_DNA.md), [schema](../VEHICLE_DNA_SCHEMA.md), and [Replay Semantics](../REPLAY_SEMANTICS.md).
