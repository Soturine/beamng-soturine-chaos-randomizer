# Sharing

Vehicle DNA can be copied as bounded JSON or packaged as a deterministic `.vdna.zip` containing only allowlisted entries. CRC32, SHA-256, manifest, schema, PNG structure, size, and path safety are validated before import.

Imported compatibility is recomputed against the receiver's installed content. The project does not provide network transport or redistribute mods.

See [Sharing details](../SHARING.md), [Vehicle DNA](VEHICLE_DNA.md), and [Security](../SECURITY.md).
