# Garage

Garage stores a bounded local Vehicle DNA library. It supports save, rename, favorite, pin, rating, tags, notes, collections, pagination, filters, details, comparison, duplicate, delete, thumbnail capture, restore, replay, mutation, import, and export.

Saving is explicit and available only after a valid final readback. Periodic UI state contains summaries, not full DNA or image bytes.

See [Gallery details](../GALLERY.md), [Vehicle DNA](VEHICLE_DNA.md), and [Sharing](SHARING.md).
