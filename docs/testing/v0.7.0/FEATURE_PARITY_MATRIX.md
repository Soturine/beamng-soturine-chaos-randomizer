## Baseline conclusion

The Angular app exposes one HUD entry with four primary tabs, three Race steps,
three Garage subsections, and a large command surface. The native Vue version is
not considered feature-complete until every row is implemented or explicitly
marked as an evidence-backed divergence in `docs/UI_MIGRATION_0.7.0.md`.
