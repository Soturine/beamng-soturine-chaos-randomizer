# v0.7.2 validation evidence

This directory separates repeatable automated evidence from owner-executed
BeamNG evidence for the experimental rescue prerelease.

- `AUTOMATED_TEST_REPORT.md`: source and package gates.
- `LIVE_TEST_PLAN.md`: 138 live cases and measurements.
- `LIVE_TEST_REPORT.md`: immutable initial pending state.
- focused reports: Runtime UI, Full Random, Race slots, i18n, and performance.
- `REQUIREMENTS_MATRIX.md`: implementation-to-evidence mapping.
- `RELEASE_CHECKLIST.md`: prerelease publication gates.

Automated tests do not establish visual, gameplay, input, FPS, or stability
success inside BeamNG. The downloaded release assets are the live-test subject.
